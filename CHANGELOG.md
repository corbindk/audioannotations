# Changelog

## 0.6.27 – first public version

- Waveform player replacing the Viewer's audio player, with note bars, drag-to-select, Mark start and
  end, loop, zoom (pinch, slider, Ctrl/Cmd + scroll) and an overview strip while zoomed.
- Text and voice notes from a box at the bottom of the player; General Comments at 0:00; private notes.
- Notes list that shows only the selected note with its replies.
- Annotations tab in the Files sidebar with replies, edit, resolve, delete and Markdown / Audacity export.
- Background waveform generation with ffmpeg, cached per file version.
- Voice notes stored in the author's files; browser WebM recordings repaired so they show their length
  and can be scrubbed.
- Daily cleanup of notes on permanently deleted files; notes removed with a deleted user.
- Rate limits on creating notes, voice notes and replies; the built-in player stays on public share pages.
- Phone layout, touch gestures and microphone access in Chromium browsers.
